🌿 Preferences

On iPad, tap “Save backup to iPad Files,” then choose Save to Files in the share sheet. This creates a separate backup copy; it does not move live app storage out of the browser.

🔐 Your data & storage

MyAssist automatically saves entries in this browser and photos in IndexedDB on this iPad. It also requests persistent storage when supported and compresses photos to reduce space. Browser storage can still be cleared or run out, so use cloud sync and save a separate backup to Files.
