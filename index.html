💾 Storage information

Checking available browser storage information.

Storage information is an estimate. Browser storage is managed by iPadOS and Safari. This does not show all storage used by your iPad.

📲 Backup to iPad Files

Create a downloadable backup of your MyAssist records and photos. Then choose Save to Files in the iPad share menu when available.

A backup is a separate copy. It does not move the live data out of browser storage.

♻️ Restore a backup

Choose a MyAssist JSON backup file to restore your saved records and photos.

Importing replaces the current saved records. Export a backup of your current data first.
